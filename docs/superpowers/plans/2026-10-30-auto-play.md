# Four-Agent Auto Play Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline and test-driven-development for behavior changes.

**Goal:** Offer manual play or a selected NPC controlling P0, with four Agents automatically playing all eight days.

**Architecture:** Persist play_mode/control status and P0 NPC, use one controlled-Agent helper, and route all model decisions through existing workers. Server runner owns automatic phase actions; human observer stays in P0's visibility boundary. Shared setup form and readonly observer UI expose mode and progress.

**Tech Stack:** Existing Node22 built-ins/browser modules, no dependencies.

**Spec:** docs/superpowers/specs/2026-10-30-auto-play-design.md.

## Global Constraints

- Manual is default; auto selects only persona. MODEL_P0 defaults to MODEL_P1.
- Four distinct NPCs; P1/P2/P3 randomly sampled from remaining nine.
- Exact 30-second private window, five outgoing messages/day per role; unchanged money/winner/secrecy.
- Four owner-only reflections before automatic next day; day8 reflects and stops.
- No gameplay submissions from observer; current-game ID checked before auto control restriction.
- Active auto resumes after restart; starting a new game stops only the authenticated previous auto game.
- Existing branch/workspace, desktop Web, local incremental commits, offline QA.

## Review Focus

- P0 must never receive human-control flags or another role's private information, or lose its own personality when projected as Agent.
- Every formerly hardcoded three-Agent loop must include auto P0 while preserving all manual behavior.
- One slow/failing provider, cancellation, late replies or a reload must not duplicate actions, reset timers, skip reflections or advance into day9.
- Starting an invalid/new game must not abandon a valid current game prematurely or leave old automatic provider work running.
- UI must be honestly read-only while server independently rejects forged observer actions; secret choices remain hidden until publication.
