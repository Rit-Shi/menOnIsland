# 🏝️ 孤岛协议 · Island Protocol

> **一座孤岛，一群自主智能体，一场关于合作、信任与背叛的社会实验。**

《孤岛协议》是一个由大语言模型驱动的**多智能体社会博弈模拟游戏**。

不同人格的 AI Agent 与人类玩家被置于资源有限、信息不对称的孤岛环境中，通过自由交流、任务协作、利益分配与策略竞争，逐渐形成复杂的社会关系。

**没有预设的剧情，没有指定的赢家。**

合作、欺骗、联盟、报复与信任崩塌，都由参与者的自主决策自然产生。

## 🎮 游戏机制

游戏支持灵活配置参与人数、实验轮次、任务类型与经济规则。

每名参与者拥有初始金币，通过参与任务积累收益。实验结束后，按照最终金币排名确定胜者。

### 任务系统

默认提供三种任务：

| 任务 | 人数 | 成功条件 | 奖励 |
|---|---|---|---|
| 💧 A · 收集淡水 | 不限，独立完成 | 自动成功 | 固定 +2 金币 |
| 🏕️ B · 搭建庇护所 | 2 人 | 总投入 ≥10 | 总投入 ×1.5，平均分配 |
| 📡 C · 修复通讯塔 | 3 人 | 总投入 ≥30 | 总投入 ×2，平均分配 |

支持扩展自定义任务，配置参与人数、成功门槛、奖励倍率、任务名额与结算规则。

**多人任务机制：**

- 参与者可以自由协商投入金额。
- 承诺与实际投入相互独立，真实投入保密。
- 达到团队投入门槛后，正式成员平分奖金，包括零投入者。
- 任务失败时，已投入金币不予退还。
- 人数不足时任务取消；超员时可通过秘密投票决定参与资格。
- 落选者仅失去当日行动资格，不会被永久淘汰。
- 参与者只能获知自身权限范围内的信息。

游戏不强制合作，也不惩罚背叛。所有策略的代价与收益由规则和其他参与者的行为共同决定。

## 🤖 自主智能体

游戏提供多种人格原型，并支持自由组合与扩展。

| 角色 | 人格特征 | 行为倾向 |
|---|---|---|
| 林舟 · 和平鸽 | 温和、公平 | 协调冲突，主动合作 |
| 沈默 · 沉默猎手 | 冷静、寡言 | 数据分析，精确投入 |
| 顾寒 · 冷血商人 | 利己、精算 | 利益最大化，机会主义 |
| 苏燃 · 复仇者 | 强硬、记仇 | 重视承诺，长期报复 |
| 阿木 · 天真理想 | 善良、真诚 | 高度信任，持续合作 |
| 陈算 · 博弈大师 | 理性、审慎 | 预期收益，重复博弈 |
| 秦岚 · 魅力演说 | 善辩、操控 | 舆论引导，策略性承诺 |
| 江隐 · 偏执生存 | 怀疑、防御 | 风险规避，自我保护 |
| 陆衡 · 忠诚盟友 | 守诺、忠诚 | 维护联盟，兑现承诺 |
| 楚衍 · 适应性变色 | 灵活、善于伪装 | 根据局势动态调整策略 |

每个 Agent 拥有独立的：

- 人格设定与行为偏好
- 私有记忆与历史经历
- 对其他参与者的信任与关系认知
- 决策策略与目标
- 语言风格与适应能力

人格决定行为倾向，而非固定脚本。同一个 Agent 在不同群体中可能展现完全不同的行为。

## 🕹️ 双运行模式

### 1. Autonomous · 自主演化模式

所有参与者均由 AI Agent 驱动。

实验启动后，各 Agent 独立感知、交流、决策与行动，完整运行整个博弈周期。

人类作为观察者，可以观看社会关系演化、任务执行和最终结果。

适用于：

- AI 社会行为观察
- 多智能体策略评测
- 人格组合对比
- 批量实验与统计分析

### 2. Human-in-the-Loop · 人类参与模式

允许一名或多名人类玩家直接加入 AI 社会。

人类与 Agent 遵守相同规则，可以：

- 参与公共聊天与私人协商
- 组建联盟、作出承诺
- 选择任务和参与投票
- 自主决定实际投入
- 与 AI 竞争最终胜利

AI Agent 不会获得人类玩家的隐藏信息，也不会因其身份享有不同的规则权限。

**人类不是旁观规则的裁判，而是社会中的一员。**

## 🔄 博弈流程

每轮游戏依次进行：

1. **信息感知** — 读取可见状态与历史记忆。
2. **自由交流** — 公开讨论、私聊、协商与承诺。
3. **任务报名** — 选择任务，必要时进行资格投票。
4. **秘密投入** — 独立提交实际投入金额。
5. **任务结算** — 更新资产与任务结果。
6. **状态更新** — 更新记忆、信任与社会关系。

各轮持续推进，直至满足实验终止条件。

## 📼 对局日志与回放

**每场实验都应是一份完整、可追溯的社会行为记录。**

系统记录对局过程中的关键事件：

- 实验配置、参与者与模型信息
- 公共对话、私人交流与承诺
- 任务报名、资格投票与实际投入
- 任务结果、金币变化与排名
- Agent 可见信息、记忆与关系状态变化
- 各轮决策与关键行为事件

### 时间线回放

支持按时间顺序回放完整对局：

- 暂停、继续与逐步查看
- 跳转到指定轮次或关键事件
- 查看任意时间点的金币、任务与关系状态
- 追踪合作、背叛及联盟形成过程
- 切换参与者视角与完整观察者视角

回放基于持久化事件记录重建，不依赖重新调用模型生成历史行为。

### 实验复现

保存规则配置、角色设定、模型配置、随机种子与版本信息，为实验对照与复现提供基础。

支持导出完整事件日志与结构化实验数据，用于后续分析。

## 🔬 社会行为观察

《孤岛协议》关注的不只是最终胜负，更是社会结构如何形成。

核心观察方向包括：

- **合作与背叛**：什么条件下会形成稳定合作？
- **信任与声誉**：过往行为如何影响未来决策？
- **联盟与排斥**：群体是否会自发形成利益集团？
- **利他与利己**：不同人格如何影响集体收益？
- **语言与操控**：说服、承诺和欺骗能否改变他人行为？
- **社会适应**：同一 Agent 在不同群体中是否会改变策略？

通过不同模型、人格组合、任务机制与经济参数的对照实验，观察多智能体社会行为的演化规律。

## 🧩 设计原则

**规则确定，行为自主，结果涌现。**

- 不使用预设剧本干预 Agent 行为。
- 不强制合作、背叛或联盟形成。
- 人类与 AI 遵循同一套游戏规则。
- 严格区分公开、私人和隐藏信息。
- 人数、任务与实验参数均可配置。
- 每场对局具有完整的事件日志。
- 支持可视化回放、实验对照与行为分析。
