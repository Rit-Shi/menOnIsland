# 孤岛协议 · ISLAND PROTOCOL

一名人类玩家与三名独立模型 Agent 的八日社交博弈游戏。唯一设计依据为 [writing-block.md](writing-block.md)。

## 启动

需要 Node.js 22 或更新版本，无需安装 npm 依赖。

```powershell
cd F:\Huawei\Island
npm start
```

浏览器访问 <http://127.0.0.1:3000>，也可以运行 `./start.ps1`。

新环境将 `.env.example` 复制为 `.env.local`，在本机填写网关地址与密钥；当前工作区的配置已经单独保存。`.env.local` 被 Git 忽略，浏览器不会收到密钥。

```dotenv
AI_BASE_URL=https://your-gateway.example.com/v1
AI_API_KEY=在本机填写
MODEL_P1=deepseek-v4.1-flash
MODEL_P2=deepseek-v4-flash
MODEL_P3=glm-5.2
```

网关须提供 OpenAI 兼容的 Chat Completions 接口。实际模型 ID 以网关列表为准；修改配置后重启服务。

模型的身份视图统一为四名独立 Agent：提示词不告知谁由人类操作，角色列表不发送 `is_human` 等控制者标记，P0 在角色列表、排名和系统播报中使用中性名称 `P0`。后台会话权限和玩家界面保留实际控制身份；角色之间的聊天保留原文，不改写其谈判内容。

## 游戏流程

1. 开始游戏，每人拥有 10 金币。
2. 每天随机选择起始角色，按编号循环进行一轮公共发言。轮到玩家时等待提交。
3. 一轮公共发言结束后，自动开启 30 秒私聊。点击名字联系对方，每名玩家或 Agent 每天跨所有对象合计最多发送 5 条，主动联系和回复共用额度。Agent 可以主动联系人类或其他 Agent，也能及时回复新私聊；没有话说时等待，不消耗额度。
4. 30 秒截止后自动进入报名，其他阶段只能阅读私聊历史。Agent 自主选择任务；玩家点击任务卡报名，截止前可修改。可请 Agent 根据最新报名重新评估（每天最多两次）；全体完成评估后锁定报名。
5. 超员时逐轮发言、秘密投票，每轮淘汰一人；继续淘汰时重新发言和投票，平票随机抽签。
6. 正式队员秘密提交整数投入，全部提交后统一结算。报名不足或被淘汰者不会转入 A。
7. 查看自己的结算，再进入下一天。第八天结束显示排名，同分允许并列第一。

| 任务 | 人数 | 成功门槛 | 奖励 |
| --- | --- | --- | --- |
| A 收集淡水 | 不限 | 无投入 | 每名执行者固定 +2 |
| B 搭建庇护所 | 恰好 2 | 全队至少 10 | 每人获得 ceil(总投入 ×1.5 ÷2) |
| C 修复通讯塔 | 恰好 3 | 全队至少 30 | 每人获得 ceil(总投入 ×2 ÷3) |

所有金额直接使用整数金币，`ceil` 表示向上取整。每人的成功奖金分别取整，实际发放总奖金等于每人奖金乘人数。例如 B 投入 5+5，每人分得 8、各净赚 3；C 总投入 31，每人分得 21。

零投入者仍平分成功奖金，失败不退还投入。详细结算仅正式队员可见，公开余额允许角色自行推算。

## 验证

```powershell
npm test
npm run check:models
```

测试离线运行，不消耗模型额度。模型检查向每个配置模型各发一次真实请求，仅输出可用性、耗时和 token 数。

## 存档与异常

- `.data/` 保存被 Git 忽略的游戏存档，每次操作使用串行事务与原子文件替换。
- HttpOnly 会话 Cookie 恢复当前游戏；刷新和服务重启不重新抽取顺序，不重复结算。
- 私聊截止时间由后端保存，刷新不会延长 30 秒；服务重启会恢复计时，已过期则进入报名。截止时取消未完成的私聊请求，不发送过期结果；各 Agent 独立请求，一个模型较慢不会阻塞其他私聊或截止切换。
- 每次私聊请求只允许发送一条消息或暂不发言；普通公开发言、报名和投票不会夹带私聊。额度校验在后端串行事务内执行，重复请求不会重复计数。
- 更新前已经在报名或之后阶段的存档继续原进度；尚未完成公共协商的对局会在该轮公聊结束后进入新私聊阶段。
- 模型异常或动作非法时，按设计兜底：报名 A、随机投给其他候选人、投入 0。异常在当天结算后显示。
- 金币余额、投入、奖金、净收益、历史和排名统一使用整数金币；状态 JSON 中 `gold: 10` 就是 10 金币。
- 旧存档首次加载时，先原样备份到 `.data/backups/integer-gold/`，再逐天按新规则重算结算和余额。保留会话、聊天、报名、投票和已锁定投入；历史聊天中的旧金额保留原文，并增加规则更新提示。
- 默认仅监听 `127.0.0.1`，为单进程本机 MVP；多人在线和云部署属于后续范围。
- 终端按 `Ctrl+C` 停止服务。开发模块通过验证后分别提交。

## 代码结构

```text
src/engine.js       状态机、校验、投票、整数结算、信誉事件
src/migrations.js   旧存档历史结算重算与版本迁移
src/observation.js  按身份过滤可见信息
src/agents.js       独立模型决策、输出校验及兜底
src/runner.js       Agent 回合推进及秘密决策快照
src/private-chat.js 独立私聊请求、收件进度、截止计时与取消
src/store.js        串行事务与原子存档
src/config.js       本地配置及公开配置过滤
server.js           会话、HTTP 接口与静态页面
public/             中文游戏界面
test/               离线测试
```
